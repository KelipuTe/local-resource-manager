## 项目说明

```
# 启动 Vue3
> npm run vue-dev
# 启动 Electron
> npm run electron-start
```

### 有哪些功能

时刻注意【本地资源管理工具】的核心目的。
减少管理【我的仓库】项目中的【资源】的工作量。
所以，实用性放在第一位，需要什么加什么。

#### 可以【查询、保存】资源的信息

需要至少支持文件名查询和信息查询两种方式。
因为资源存在【一个名字对应一个文件】和【一个名字对应多个文件】两种形式。
信息查询是为了减少处理【一个名字对应多个文件】这种形式的资源的工作量。

### 注意事项

不要有代码洁癖，合适才是最好的。

#### 模块化的问题

这个项目搞的是桌面应用，相当于只有客户端。
模块化的粒度不用太细。我感觉【一个 js 文件】对应【一个功能模块】就差不多了。

#### 字段名的问题

这个项目搞的是桌面应用，相当于只有客户端。
一个数据库模型，从上用到下或者透传，没什么大问题。
不要完全参考 AI 写的代码。不要完全照搬那些所谓的最佳实践。

查询时如果用了别名可能会麻烦一点，回传回来的时候需要特别处理。

#### IPC 的问题

这个项目搞的是桌面应用，相当于只有客户端。
和【客户端-服务端】结构那种需要前后端分离的结构不太一样。
所以不需要按照 API 的标准去搞 Electron 的 IPC 。
