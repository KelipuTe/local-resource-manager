## 项目说明

本地资源管理工具

Electron + Vue3 + Node.js + SQLite

### 常用命令

```
# 安装依赖包
> cnpm install

# 启动 Vue3
> npm run vue-dev

# 启动 Electron
> npm run electron-start
```

### 有哪些功能

时刻注意【本地资源管理工具】的核心目的。
减少管理【我的仓库】项目中的【资源】的工作量。
所以，实用性放在第一位，需要什么加什么。

#### 可以【查询、保存】资源的信息

#### 可以【批量重命名、批量归档】资源

#### 可以对资源【打标签】

#### 可以通过标签【搜索、导出】资源

### 注意事项

不要有代码洁癖，合适才是最好的。

#### 模块化的问题

这个项目搞的是桌面应用，相当于只有客户端。
模块化的粒度不用太细。我感觉【一个 js 文件】对应【一个功能模块】就差不多了。

#### 数据库字段的问题

这个项目搞的是桌面应用，相当于只有客户端。
一个数据库模型，从上用到下或者透传，没什么大问题。
不要完全参考 AI 写的代码。不要完全照搬那些所谓的最佳实践。

查询时如果用了别名可能会麻烦一点，回传回来的时候需要特别处理。

#### 数据库数据的问题

有些数据不需要太详细。

比如，资源的发布时间，记录年月日就可以了，记录时分秒则没有必要。

如果能搞到资源的元数据，最好存一份资源的元数据。

Bilibili 的资源，用的是哔哩下载姬下载的。
哔哩下载姬，可以在【设置=>视频】里面设置【生成视频元数据】。

Pixiv 的资源，用的是【FireFox 浏览器】的【Pixiv 工具箱】插件下载的。
Pixiv 工具箱，没办法获取元数据，只能下载的时候，设置在文件名里面。

#### IPC 的问题

这个项目搞的是桌面应用，相当于只有客户端。
和【客户端-服务端】结构那种需要前后端分离的结构不太一样。
所以不需要按照 API 的标准去搞 Electron 的 IPC 。
